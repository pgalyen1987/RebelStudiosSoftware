What the plugin does when the licence check cannot complete

the check fails
Outage, blocked request, DNS timeout It will happen eventually, and it is not the paying customer's fault.
grace window
Pro keeps working On the cached last-good verification. Re-check quietly in the background.
only after it expires
Stop features, never data No new Pro actions. Everything already created stays intact and exportable.
And never block admin_init on a network request: a slow licence endpoint is a hung dashboard for every user.
