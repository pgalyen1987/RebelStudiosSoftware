Combine Photos into One Clean PDF

You photographed the pages — now make it a real document

August 10, 2026 Patrick Galyen

You photographed a stack of pages — a signed form, a lease, a set of receipts, a handwritten application. Now the other side wants one PDF, in order, not twelve loose image attachments they have to piece together.

It’s a small task that’s weirdly easy to get wrong: pages out of order, sideways, or a file so huge it bounces off an email limit. Here’s how to do it cleanly.

Free Ways to Do It

  • iPhone: open the Files app, select the images in the order you want, tap … → Create PDF. (Or use Notes → the built-in document scanner for a cleaner, deskewed result.)
  • Mac: select the images in Finder in order → right-click → Quick Actions → Create PDF.
  • Windows: select the images → right-click → Print → choose Microsoft Print to PDF.
  • Scanner apps: most phone scanner apps combine captured pages into a PDF, often with edge detection.

For a few tidy photos, one of these gets you there for free.

Where It Gets Messy

  • Page order — the OS often orders by filename or capture time, not the order you want.
  • Skew and rotation — handheld photos come out tilted; a raw “images to PDF” keeps them tilted.
  • File size — full-resolution phone photos make a bloated PDF that won’t fit an upload or email cap.
  • Consistency — mixed orientations and sizes make an ugly, hard-to-read document.

If the PDF Comes Out Too Big

A document built from full-res photos can be tens of megabytes. If it’s over an upload or email limit, you don’t need to re-shoot — rebuild it from compressed images or get it under the cap. Photos scanned at phone resolution rarely need to be as large as they are.

FAQ

How do I control the page order?

Select or provide the images in the order you want them. If your OS reorders by filename, rename them 01, 02, 03 first.

Can I mix in a photo and a screenshot?

Yes — any images combine into the PDF. Consistent orientation and similar sizes read best.

Will the PDF be searchable?

A PDF built from photos is images of pages, not selectable text. If you need the text extracted, run it through OCR instead.
