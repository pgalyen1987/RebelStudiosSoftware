Invoice Documents Pro

Bulk PDF printing for the free Rebel Studios Invoice Documents plugin. Tick any number of orders on the WooCommerce Orders list, choose Print invoices (PDF), and get one file with a page per order.

What it adds

This is the complete list. It does one job, and the page below says what it does not do rather than leaving you to find out.

Bulk print invoices

Select orders on the Orders list, choose “Print invoices (PDF)”, and a single PDF comes back with one page per order.

Bulk print packing slips

The same for the warehouse copy, so a day’s picking list is one document rather than fifty tabs.

Why the output looks identical

A bulk printer that renders documents differently from your single-document output is worse than no bulk printer, because you end up with two invoice designs in circulation and a customer eventually notices.

This reuses the free plugin’s renderer, styling and PDF engine rather than implementing a second one. Whatever logo, accent colour, font and footer you have configured come through unchanged, because it is the same code path with a loop around it. There is no separate template to configure and no second place for your branding to drift out of step.

When the host has no PDF engine

Shared hosting sometimes lacks what a PDF engine needs. The failure mode matters more than the feature, because it happens on somebody else’s server at the worst moment.

Rather than erroring, the batch opens as a clean printable page — the same documents, in the browser, ready for the print dialogue and its own “save as PDF”. You are never left with a spinner and a blank screen, and the warehouse still gets its paper.

What it does not do

Worth stating plainly, because earlier versions of this page listed features that were never built and the honest version is shorter:

  • No custom document templates. You get the free plugin’s layout with your branding applied, not a template editor.
  • No credit notes or refund documents. Not built.
  • No extra tax or B2B fields beyond what the free plugin already renders.

If any of those is what you came for, this is not the product, and buying it will disappoint you. It bulk-prints. That is the whole thing, and for a store doing volume it is the part that saves real time.

What is in the download, and what you need

Both plugins: this Pro add-on and the free Rebel Studios Invoice Documents for WooCommerce plugin it builds on. Upload both zips and you are running; there is nothing to source separately. You get a licence key after checkout to paste into the plugin’s settings.

One caveat stated plainly: the free plugin is not in the WordPress.org directory yet, so searching for it from inside WordPress will not find it. That is worth knowing if you wanted the free plugin on its own, and irrelevant to a buyer — the file is in your download.
