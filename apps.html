Indemnity (INDN)

An ERC-20 token where ordinary transfers are held in on-chain escrow for 7 days instead of settling instantly, so a payer who has been defrauded can dispute before the money is gone. DEX swaps settle instantly via an owner-managed exemption allowlist.

It was never launched. The dispute mechanism is written against the Kleros arbitration interfaces (ERC-792 / ERC-1497), but an arbitrable contract has to be whitelisted by a Kleros court before a jury can actually hear a case, and that whitelisting never came through. Without it the escrow holds funds and the timeout releases them, but no dispute can be adjudicated, which is the whole point of the token. The code is public and the design is sound on paper; treat it as an unshipped prototype, not a product.

What the contract implements

  • Escrow-by-default transfers with a 7-day dispute window
  • Arbitration hooks written against ERC-792 / ERC-1497, never activated, as no court whitelisted the contract
  • DEX exemption allowlist for instant swaps
  • Stuck-dispute escape hatch (180-day timeout)

Vigilo

An open-source research prototype that learns normal device behavior from Zeek connection logs and flags anomalies as forecast error. Detects port scans, DDoS, and noisy botnet traffic on consumer CPU hardware with no cloud dependency.

Key Features

  • 75% detection at 1% FPR on IoT-23 (20 malware families)
  • Runs entirely on CPU, no GPU or cloud required
  • SPAN/mirror, gateway Zeek, or lab capture workflows
