Indemnity (INDN)

An ERC-20 token where ordinary transfers are held in on-chain escrow for 7 days instead of settling instantly. During that window the payer can open a dispute and a decentralized Kleros jury decides who receives the funds. DEX swaps settle instantly via an owner-managed exemption allowlist.

Checkout Brasil

The Brazilian WooCommerce checkout stack, maintained.

The plugin 60,000 Brazilian stores rely on has not shipped since February 2024 and predates both HPOS and the block checkout. On a block checkout it adds no fields at all — stores silently stop collecting CPF and find out when an invoice is rejected. This replaces it.

Built from the incumbent's own one-star reviews

  • Every field independently off / optional / required — CPF included
  • Razão Social field the incumbent never had
  • CEP fills the address; CNPJ fills the company, server-side and cached
  • Documents reach the order, admin, emails and API — ready for NF-e
  • Official mod-11 check digits, validated in the browser and again on the server
  • A lookup outage never blocks a sale

An open-source research prototype that learns normal device behavior from Zeek connection logs and flags anomalies as forecast error. Detects port scans, DDoS, and noisy botnet traffic on consumer CPU hardware with no cloud dependency.
