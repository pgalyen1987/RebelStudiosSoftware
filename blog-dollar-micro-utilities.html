Utilities for $1. Agents welcome.

Price upfront for humans — HTTP 402 for machines

August 4, 2026 Patrick Galyen

Most “free tools” are not free. They are lead magnets: email gates, watermarked downloads, usage meters that flip to a $12/month plan the moment you need a second file.

We took the opposite bet with the Rebel Studios $1 tools catalog: show the price, charge once, deliver the file or the JSON, stop talking.

Why $1

One dollar clears the psychological bar for “this is worth not fighting with free junk” while staying above the ~$0.50 floor of card networks. It is also large enough that we can afford real compute (HEIC decode, image recompress, on-chain risk checks) without needing a subscription to amortize costs.

Two Buyers, One Endpoint

Humans want a button and a card form. AI agents want an HTTP status code and a machine-readable invoice. Those are not two products — they are two payment rails on the same utility:

  • Humans — open the tool page, pay $1, download the result (via gate402.app/tools)
  • Agents — POST the API, receive 402 Payment Required, pay in USDC via x402, retry, get JSON

If you want the protocol deep-dive, read HTTP 402 Payment Required and the practical x402 monetization guide.

What Is Live vs Coming Soon

Live today: upload fixing, HEIC→JPG, under-X MB, exact image fit, metadata strip, JSON repair, CSV↔JSON, Base contract scan, ABI decode. The heavier document/AI tools (ATS resume, fillable PDF, OCR, etc.) are listed at the same $1 price so the catalog is honest about directionality — we do not fake a checkout on vaporware.

SEO is the acquisition layer

People search “heic to jpg” and “file too large 5 MB.” Agents search catalogs and x402.json. The human web and the agent web can share one utility engine. That is the point of wiring Rebel Studios pages to Gate402 endpoints.

The Takeaway

If a problem is worth five minutes of rage, it is worth a dollar. Browse the tools hub, pick the pain you have, pay once. If you are building an agent that needs the same capability, hit the endpoint on the tool page and bring a wallet that speaks 402.
