Services

What we take on

Phone apps

Phuzzles is one Firebase backend with two native apps on top: Kotlin and Jetpack Compose on Android, Objective-C on iPhone. Oops All Knights is one React Native codebase for both stores and the browser. We write the store listing, fill in the privacy forms and answer the reviewers.

  • Kotlin + Jetpack Compose
  • Objective-C / React Native (Expo)
  • Firebase: Auth, Firestore, Functions, FCM
  • Google Play Console + App Store Connect

Web apps and SaaS

TradeGuard reads insurance certificates, tracks every expiry date and bills through Stripe. Accounts, payments, a database and an AI step are the usual shape of the job, and we deploy it and keep it running.

  • Next.js + TypeScript
  • Prisma + PostgreSQL / SQLite
  • Stripe billing
  • Claude API

WordPress and WooCommerce plugins

Four WooCommerce plugins so far, for event tickets, PDF invoices, restaurant menus and members-only content, each with a paid Pro add-on. If your store needs one thing WooCommerce doesn’t do, that is a plugin we can write.

  • PHP + WooCommerce hooks
  • WordPress.org review rules
  • Licence checks for paid add-ons
  • Tested on a real store before release
