Dev Toolbox for VS Code

Fifteen everyday developer transforms, right on your editor selection. Open the Command Palette, type Dev Toolbox, and convert — no copy-pasting into web tools.

What it does

JSON tools

Format, minify, and repair broken JSON (smart quotes, trailing commas, unquoted keys) in place.

Convert anything

CSV ↔ JSON, JWT decode, Base64 encode/decode, URL encode/decode — on the selected text.

Text & case

Sort lines, remove duplicates, and convert to camelCase / snake_case / kebab-case.

Local & private

Everything runs in the editor. No network, no telemetry, no accounts.

All fifteen transforms

Every one of these operates on your current selection and replaces it in place. Nothing leaves the editor.

  • JSON: format, minify, and repair — the repair pass fixes smart quotes, trailing commas, unquoted keys and single-quoted strings, which is most of what breaks a config file or a model’s output.
  • CSV → JSON and JSON → CSV, honouring quoted fields so a value like "Smith, Jr." survives the round trip instead of splitting into two columns.
  • JWT decode — header and payload, expanded in place.
  • Base64 encode and decode.
  • URL encode and decode.
  • Lines: sort, and remove duplicates.
  • Case: camelCase, snake_case, kebab-case.

Why this belongs in the editor

Every one of these transforms already exists as a website, and that is precisely the problem. The web version costs you a context switch, a paste out, a paste back, and a moment of not thinking about the thing you were actually doing.

The more serious cost is what you paste. A JWT from your staging environment is a live credential. A config blob is often full of internal hostnames, bucket names and account identifiers. A CSV pulled from production may be customer data. Pasting any of that into a free web utility means handing it to a server you know nothing about, run by someone with no obligation to you — and the habit is hard to break once it is a habit, because the tool that is one tab away is the tool you use at 5pm on a Friday.

Running the transform locally removes the decision entirely. There is no network call to audit, no retention policy to read, and no difference in behaviour between the token you were allowed to paste and the one you were not.

How you use it

Select the text. Open the Command Palette — Ctrl+Shift+P, or Cmd+Shift+P on a Mac — and type Dev Toolbox. Pick the transform. The selection is replaced.

Because the commands live in the palette, the ones you reach for most surface first as VS Code learns your habits, and you can bind any of them to a keystroke through the normal keyboard shortcuts editor if a particular transform becomes muscle memory.

What it deliberately does not do

It does not lint, validate against a schema, or tell you whether your JSON is correct — only whether it parses, and how to make it parse. It does not verify a JWT’s signature; decoding is not verification, and any tool implying otherwise is teaching a dangerous habit. It has no accounts, no settings to sync, no telemetry, and no network permission at all.

That last constraint is deliberate. An extension with no network access cannot leak your selection even if it wanted to, and that is a much stronger promise than a privacy policy.
